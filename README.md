# Kautum Krishnan — portfolio

Personal portfolio site. MSc Data Science, King's College London.

Built with Next.js (App Router) and plain CSS. The hero includes a small draggable
"evaluation protocol" instrument comparing the dissertation's random-split score
(0.9002 macro-F1) against the honest attacker-machine-holdout score (0.6059) — real
pointer-driven 1:1 tracking with a critically-damped spring snap, not a static graphic.

## Develop

```bash
npm install
npm run dev
```

## Content sources

Every fact on this site (dissertation numbers, project descriptions, skills) is drawn
from the verified project catalog maintained in the `job applies` job-search wiki —
nothing here is invented.
